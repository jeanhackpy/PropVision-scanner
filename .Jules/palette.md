## 2024-05-22 - Copy-to-Clipboard Feedback
**Learning:** Providing immediate visual feedback (changing text/icon for 2 seconds) when copying to clipboard significantly improves perceived responsiveness and user confidence.
**Action:** Always implement a temporary 'Copied!' state for clipboard interactions.

## 2024-05-22 - Agent Card Discoverability
**Learning:** Features locked behind complex flows (like AI scanning) might never be seen by users. Surfacing agents in the primary map view increases engagement with agent-related features.
**Action:** Surface relevant secondary entities (like agents) in main search result views to improve feature discoverability.
