## 2026-08-09 - Semantic Dialers and Resilient API Fallbacks
**Learning:** For contact buttons representing telephone numbers (such as in AgentCard), replacing placeholder button components with a semantic anchor (<a>) wrapping a 'tel:' protocol leverages browser/device native dialers. Additionally, implementing resilient try-catch fallback structures inside client-side API integrations prevents application lockup or infinite loading states when external API keys (e.g. Gemini) are missing or invalid, keeping the visual interface functional.
**Action:** When designing interactive contact elements, prioritize native protocols like 'tel:' and 'mailto:' instead of custom click behaviors. For any external API integrations, always provide a robust client-side simulation fallback to ensure smooth user experience under failing network/key conditions.
