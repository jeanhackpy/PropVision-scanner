## 2025-02-23 - Native Telephone Protocol for Agent Contact Actions
**Learning:** Contact buttons displaying agent phone information are more accessible and useful when rendered as semantic anchor (`<a>`) elements using the `tel:` scheme with explicit `aria-label` attributes and focus visible styles, rather than generic button elements.
**Action:** Always prefer semantic `<a>` tags with `tel:` protocols and clear `aria-label`s for telephone contact triggers in cards and lists.
