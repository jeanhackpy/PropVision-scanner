## 2025-07-16 - Keyboard Accessibility with Overflow Boundaries and Bottom Sheet Controls
**Learning:** In applications utilizing Tailwind CSS maps or sheet layouts that use `overflow-hidden`, standard keyboard focus rings (e.g. `ring-2`) can be visually clipped or invisible because they render outside the container border. Utilizing `focus-visible:ring-inset` ensures the focus indicator is rendered within the element boundaries, maintaining WCAG visual accessibility. Additionally, interactive drag/minimize handles of bottom sheets should provide focus indicators on the container receiving the click and key listener to avoid nested interactive element confusion.
**Action:** Always apply `focus-visible:ring-inset` on focusable components with overflow restrictions and bind access controls directly on semantic wrappers when implementing visual drag handles.
