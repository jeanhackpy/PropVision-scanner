## 2025-07-29 - Device-Native Dialing & Accessibility
**Learning:** Replacing generic placeholder contact buttons with semantic anchor elements utilizing the `tel:` protocol ensures seamless transition to native dialers on mobile devices and native call programs on desktops. Adding explicit ARIA labels and focus-visible ring styles provides necessary context to assistive technologies and enhances keyboard navigation.
**Action:** Always wrap phone numbers or contact actions in semantic anchors with the `tel:` protocol, explicit screen-reader labels, and robust focus outline styles.
