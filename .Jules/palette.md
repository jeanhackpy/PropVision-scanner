## 2025-08-07 - Semantic Telephone Linking in Real Estate Agent Cards
**Learning:** Placeholders for primary direct-communication channels (such as generic button click handlers representing phone numbers) underperform in accessibility and responsiveness. Utilizing semantic anchor (`<a>`) elements with the `tel:` protocol permits mobile browsers and native device applications to seamlessly dial the agent directly. Explicitly detailing the contact context and number within an `aria-label` provides a frictionless experience for screen-reader users, while customized focus rings prevent keyboard navigation clipping.
**Action:** Replace placeholder buttons that trigger communication with semantic, interactive `<a>` links utilizing native device schemes (like `tel:` or `mailto:`), ensuring rich accessibility attributes and distinct visible focus states.
